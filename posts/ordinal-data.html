Ordinal Data

Definition, Examples, and Difference from Nominal

In the previous blog, we looked at Nominal Data — data used to name or label categories.

Now let's make one small but important change.

What if those categories have an order?

Imagine a customer rates a service:

Poor → Average → Good → Excellent

There is a clear order here.

Excellent is above Good.

Good is above Average.

Average is above Poor.

But can we say that the difference between Good and Excellent is exactly the same as the difference between Average and Good?

Not necessarily.

And that is the interesting idea behind Ordinal Data.

What Is Ordinal Data?

Ordinal data is categorical data where the values have a meaningful order or ranking.

Category + Order = Ordinal Data

Some everyday examples:

  • Satisfaction → Poor, Average, Good, Excellent
  • Competition → 1st, 2nd, 3rd
  • Education level → School, Undergraduate, Postgraduate
  • Agreement → Strongly Disagree → Disagree → Neutral → Agree → Strongly Agree
  • T-shirt size → Small, Medium, Large, XL
  • Spiciness → Mild, Medium, Hot, Very Hot

In all these examples, we can say that one category comes before or after another.

Nominal vs Ordinal

This is where students often get confused.

Nominal Data

Consider:

Department:

CSE   |   ECE   |   EEE   |   Mechanical

There is no meaningful ranking.

CSE is not "higher" than ECE.

So:

Nominal → Category, No Order

Ordinal Data

Now consider:

Performance:

Poor → Average → Good → Excellent

Here, there is a meaningful ranking.

So:

Ordinal → Category + Order

That's the easiest way to remember the difference.

What About Numbers?

Ordinal data can also use numbers.

For example:

1st → 2nd → 3rd

These numbers tell us the position or rank.

But be careful.

If one student finishes 1st and another finishes 2nd, we know the first student ranked higher.

We don't automatically know how much better the first student was.

That's an important distinction.

A Simple Example

Imagine a feedback form:

How satisfied are you with the course?

You provide four options:

1 — Poor
2 — Average
3 — Good
4 — Excellent

The numbers make it easy to store and analyse the responses.

But the numbers are representing ordered categories.

The jump from 1 to 2 doesn't necessarily represent the same amount of satisfaction as the jump from 3 to 4.

So the numbers indicate rank, not necessarily a precise measurement.

When Do We Use Ordinal Data?

Ordinal data is useful when we want to:

Rank → Order → Compare

For example:

  • Ranking students in a competition
  • Measuring satisfaction
  • Recording levels of agreement
  • Classifying severity
  • Recording performance levels
  • Representing product ratings

Whenever the order matters, but the exact difference between categories isn't necessarily measurable, ordinal data can be appropriate.

One Simple Rule

Ask yourself two questions:

1. Are these categories?

2. Do the categories have a meaningful order?

If the answer is:

Yes + No → Nominal

Yes + Yes → Ordinal

Remember:

Nominal = Name

Ordinal = Order

That's it.

A small difference in the name...

but a very important difference when we start analysing data.

From Nominal to Ordinal

So far, our journey looks like this:

Qualitative Data

↓

Nominal → Categories without order

Ordinal → Categories with order

And this is just the beginning.

Once we understand what kind of data we have, we can start asking a much more interesting question:

What can we actually do with it?
Data thinking begins with understanding the data.
