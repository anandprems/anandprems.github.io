Interval Data

Understanding Equal Differences — But No True Zero

So far, we have explored:

Nominal Data → Categories without order

Ordinal Data → Categories with order

Now let's take one more step.

What if the values have an order, and the difference between values is meaningful and consistent?

That brings us to Interval Data.

What Is Interval Data?

Interval data is numerical data where:

  • Values have a meaningful order
  • The difference between values is meaningful
  • The intervals between values are equal
  • But there is no true zero

That last point is the interesting one.

Let's see why.

Temperature Is a Simple Example

Consider temperature in Celsius:

10°C → 20°C → 30°C → 40°C

The difference between:

10°C and 20°C = 10°C

20°C and 30°C = 10°C

30°C and 40°C = 10°C

The intervals are equal.

So we can meaningfully say:

30°C is 10°C warmer than 20°C.

But there is something we cannot say:

40°C is twice as hot as 20°C. ❌

Why?

Because 0°C does not mean "no temperature."

Zero is simply a point on the Celsius scale.

That's what makes temperature in Celsius an example of Interval Data.

The Important Idea: No True Zero

This is probably the easiest way to remember interval data.

Imagine a scale where:

0 does not mean "nothing exists."

That is a clue that you may be dealing with interval data.

For Celsius:

0°C ≠ No temperature

There is still thermal energy at 0°C.

The zero is simply a reference point on the scale.

Some Examples

Common examples that are often treated as interval data include:

  • Temperature in Celsius
  • Temperature in Fahrenheit
  • Calendar years
  • IQ scores

Consider calendar years:

2000 → 2010 → 2020

The difference between 2000 and 2010 is 10 years.

The difference between 2010 and 2020 is also 10 years.

But the year 0 does not represent "no time."

So calendar years demonstrate the idea of an interval scale.

Interval vs Ordinal

This is an important difference.

Ordinal Data

Poor → Average → Good → Excellent

We know the order.

But we cannot assume the difference between categories is equal.

Interval Data

10°C → 20°C → 30°C → 40°C

We know the order.

And the difference between consecutive values is meaningful and equal.

Ordinal = Order

Interval = Order + Equal Intervals

What Can We Do With Interval Data?

Because the differences are meaningful, we can perform many mathematical and statistical operations.

For example, we can calculate:

Difference
40°C − 20°C = 20°C

We can also calculate measures such as the mean.

But we should be careful with statements involving ratios.

For example:

40°C is twice as hot as 20°C. ❌

That doesn't make sense on the Celsius scale.

If we want to make ratio-based statements about temperature, we need a scale with a true zero, such as Kelvin.

One Simple Way to Remember

Think about the four questions:

1. Are there categories?

2. Is there an order?

3. Are the intervals equal?

4. Is there a true zero?

For Interval Data:

Order → Yes ✅

Equal intervals → Yes ✅

True zero → No ❌

That's the key.

The Bigger Picture

Our journey is becoming clearer:

Nominal
↓
Categories

Ordinal
↓
Categories + Order

Interval
↓
Order + Equal Intervals

And there is still one more important level waiting for us:

Ratio Data

Where we finally get something Interval Data doesn't have:

A true zero.

And that small difference changes what we can say about the numbers.

Remember

Interval Data = Equal Differences, No True Zero

So the next time you see a temperature of 20°C, don't just look at the number.

Ask:

“What does zero actually mean here?”

Sometimes, understanding the meaning of zero is more important than understanding the number itself.
