Types of Data

Qualitative vs Quantitative — Understanding the Two Faces of Data

In my previous blog, “Why Data?”, we looked at why data has become so important.

But before we analyse data, build models, or talk about Artificial Intelligence, there is a very basic question we need to ask:

What kind of data do we actually have?

Not all data looks the same.

Some data tells us how much.

Some tells us what kind.

And understanding this difference is one of the first steps in working with data.

Two Broad Types

At a very basic level, we can think of data in two broad categories:

Qualitative Data
Quantitative Data

The easiest way to remember the difference is:

Qualitative → Quality / Category
Quantitative → Quantity / Number

Qualitative Data — “What Kind?”

Qualitative data describes qualities, characteristics, or categories.

  • Eye colour → Brown, Blue, Green
  • Feedback → Excellent, Good, Poor
  • Type of food → Vegetarian, Non-vegetarian
  • Product category → Electronics, Clothing, Grocery
  • Mood → Happy, Sad, Excited

Notice something?

We are describing what something is like, rather than measuring it with a number.

“The student is confident.”

“Confident” is qualitative.

Quantitative Data — “How Much?”

Quantitative data deals with numbers and measurements.

  • Age → 21 years
  • Height → 172 cm
  • Temperature → 32°C
  • Number of students → 60
  • Marks → 87
  • Heart rate → 72 BPM

Here, we can count or measure the value.

“The student scored 87 marks.”

87 is quantitative data.

One Simple Example

Imagine you are analysing a classroom.

You collect this information:

Name: Arun
Age: 20
Department: CSE
Favourite subject: Artificial Intelligence
Attendance: 92%

Data Type
Name Qualitative
Age Quantitative
Department Qualitative
Favourite subject Qualitative
Attendance Quantitative

So the same student can generate both kinds of data.

And real-world datasets usually do exactly that.

Why Does This Matter?

Because the type of data influences how we analyse it.

You wouldn't analyse:

“Favourite colour = Blue”

in the same way as:

“Age = 21”

You might count categories, compare groups, or look at patterns in qualitative data.

For quantitative data, you might calculate:

Average → Minimum → Maximum → Distribution → Correlation

Understanding the data comes before choosing the analysis.

A Small Thought

When we hear the word “data”, many of us immediately imagine rows and columns filled with numbers.

But data is much more than numbers.

A patient's symptoms.

A student's feedback.

A customer's opinion.

A photograph.

A voice recording.

A heart signal.

A temperature reading.

All of these can become data.

And before asking:

“What can we do with this data?”

we should first ask:

“What kind of data is this?”

That simple question is often the beginning of good data analysis.

Data Thinking Begins Here

Data is not just numbers.

Some data tells us what.

Some data tells us how much.

And understanding the difference is where data thinking begins.
